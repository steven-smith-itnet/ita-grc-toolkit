IT Controls Assurance Toolkit

A reusable toolkit of scripts & templates for IT audit and GRC — evidence, testing, reporting & policy-as-code

Toolkit Overview

Toolkit Modules

The toolkit is organized into cohesive modules that map to the assurance lifecycle — collect evidence, analyze access, test controls, report, and enforce guardrails. Each module ships with sample inputs and a documented run sequence.

ModulePhaseNameToolingStatus

Click any module to expand its description, inputs/outputs, and numbered run sequence.

Automation Code

The engineering behind the modules — a control test runner and Jinja2 report generator in Python, a Bash ITGC evidence collector, PowerShell access review with SoD detection, SQL audit sampling, an Ansible baseline play, a GitHub Actions gate, and the OPA/Rego policy it enforces.

Multi-Cloud Compliance Guardrails

The same control intent expressed as infrastructure-as-code across all three major clouds — AWS Config rules & SCPs, Azure Policy via Bicep, and GCP Organization Policy constraints.

Framework Mapping

Every toolkit check carries references to multiple control frameworks, so a single automated test produces evidence for NIST 800-53, CIS Controls, ISO 27001, and SOC 2 at once.

Architecture & CI Pipeline

How the modules compose into a pipeline: evidence and tests feed a framework crosswalk; guardrails and a CI policy gate keep infrastructure from drifting out of compliance.

Spreadsheet Artifacts

The toolkit still speaks the auditor's language. It emits a Risk-Control Matrix (RCM) and an audit checklist as plain CSV, ready for the workpaper store or a GRC platform import.
